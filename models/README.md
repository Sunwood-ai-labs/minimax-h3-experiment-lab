# External model inventory

The model weights are intentionally excluded from Git. `manifest.json` is the tracked lock file for the external assets: it records the Hugging Face repository, immutable revision, target path inside `models/`, byte count, and SHA-256 for every file referenced by the committed workflows.

Choose a profile before downloading:

| Profile | Use for | Approx. download |
|---|---|---:|
| `fl2va` | baseline, Motion Context, cat-café Vlog, and J-pop MV | 42.5 GB |
| `ref2va` | multi-reference R2V | 42.5 GB |
| `fl2va-lightx2v` | 4-step / ImageGen-started I2V | 44.5 GB |
| `ref2va-lightx2v` | ref2va 6-vs-20-step and acceleration | 44.5 GB |
| `legacy-turbo` | retained legacy Turbo diagnostic workflow | 56.3 GB |

PowerShell example:

```powershell
Copy-Item .env.example .env
(Get-Content .env) -replace '^H3_PROFILE=.*', 'H3_PROFILE=ref2va-lightx2v' | Set-Content .env
docker compose --profile download run --rm model-downloader
```

The downloader checks both size and SHA-256 after every file. It does not download generated MP4s or Motion Context latent cache files; those are run outputs and must be generated by the corresponding experiment workflow.

Sources: [Comfy-Org/MiniMax-H3](https://huggingface.co/Comfy-Org/MiniMax-H3), [Kijai/MiniMax-H3_comfy](https://huggingface.co/Kijai/MiniMax-H3_comfy), and [larryvrh/MiniMax-H3-Turbo-Lora](https://huggingface.co/larryvrh/MiniMax-H3-Turbo-Lora).
