## Reading an experiment

- **README**: hypothesis, conditions, prompt, timings, conclusion, and limitations.
- **Frame tile**: tracked visual evidence for a quick temporal review.
- **`experiment.json`**: structured parameters, run IDs, hashes, output paths, and public-evidence status.
- **Contact-sheet manifest**: source video paths, sample timestamps, dimensions, duration, and SHA-256.
- **Video**: usually `local-only`; generated MP4s are intentionally excluded from the normal Git payload to keep clones and Pages lightweight.
