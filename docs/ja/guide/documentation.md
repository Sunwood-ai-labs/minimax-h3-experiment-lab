# ドキュメントの言語方針

このリポジトリは、日本語と英語の両方で読める構成にします。公開用のガイドと実験の入口は、原則として英語版と日本語版を用意します。

## ペアのルール

- ルート入口は `README.md`（英語）と `README.ja.md`（日本語）です。
- VitePressは `docs/guide/*.md`（英語）と `docs/ja/guide/*.md`（日本語）を対応させます。
- 実験記録は `README.md` を英語default、`README.ja.md` を日本語版として統一します。両方から相互リンクし、`experiment.json`、追跡済みフレームタイル、X動画・参照URL、workflow導線を示します。
- 既存ファイル名を使っている共通ガイドは、`LAB.md` + `LAB.en.md`、`experiments/index.md` + `experiments/index.en.md`のように言語サフィックスでペアにします。
- モデル入力が英語のプロンプトは英語のまま保持します。ただし、周辺の説明と再現メタデータには日本語版または日英併記を用意します。

## 対象外

生のbenchmarkレポート、生成されたシミュレーターpayload、ツールが管理する `AGENTS.md` / `CLAUDE.md`、投稿文の下書きは、読者向けガイドではなく証跡・入力アーティファクトです。日英の索引から辿れるようにし、逐語訳は必須にしません。

ただし、対象外のファイルだけに実験の結論、公開URL、再現手順を置いてはいけません。必ず日英の入口から到達できるようにします。

## レビューチェックリスト

Markdownを追加するときは、次を確認します。

1. 公開ガイド、実験入口、出典・プロンプトメモ、生成証跡のどれかを分類する。
2. 対応言語版を追加するか、直近の日英索引で対象外であることを明示する。
3. URL、workflowパス、status、処理時間、hash、local-only境界を言語版間で一致させる。
4. `scripts/validate-documentation-parity.ps1`と通常の実験validatorを実行する。
